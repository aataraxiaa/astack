# AStack plugin

Shared PStack-derived skills for Claude Code and Codex, with Apple development guidance. The native manifests register the `astack` plugin. Start with `poteto-mode`; `setup-pstack` retains its upstream skill name and writes AStack's own model configuration.

The repository README documents installation. Source pins and adaptation decisions live in tools/upstream.json and tools/forks.json. Future updates follow original cursor/plugins directly. pstack-claude is the attributed one-time portability bootstrap.
