# AStack plugin

Shared PStack-derived skills for Claude Code and Codex. The native manifests register the `astack` plugin. Start with `auto`; `setup-astack` configures AStack's models and session hook.

The repository README documents installation. Source pins and adaptation decisions live in tools/upstream.json and tools/forks.json. Future updates follow original cursor/plugins directly. pstack-claude is the attributed one-time portability bootstrap.
