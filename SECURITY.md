# Security

Report security issues privately to the maintainers of the repository distributing your AStack copy. Use its private vulnerability reporting feature if enabled, or request a private contact without including vulnerability details. Do not send AStack reports to upstream or the portability reference maintainer unless their code is affected.

Scope includes skills, hooks, scripts, adaptation tooling, and release automation. Preserve source pins and keep validation isolated from publication credentials. Follow the release gates in [the upstream workflow](docs/upstream.md). AStack makes no security guarantee for untested future upstream changes.
