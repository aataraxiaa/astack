# Security

AStack is a private repository owned by aataraxiaa. Report security issues to its owner using a private channel; do not send AStack reports to the port reference maintainer.

Scope includes skills, hooks, scripts, adaptation tooling, and release automation. Report unintended execution, data access, credential exposure, and update-chain weaknesses privately to the AStack repository owner .

Preserve source pins and keep validation isolated from publication credentials. Follow the release gates in docs/upstream.md. AStack makes no security guarantee for untested future upstream changes.
